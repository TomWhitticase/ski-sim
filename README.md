# mountain-map

A 3D immersive simulation of real-world ski resorts, built from real geospatial data: elevation models, aerial imagery, OpenStreetMap piste and lift data, buildings and vegetation. The aim is for each resort to match reality as closely as the available data allows.

**Status:** planning. No code yet. See [CLAUDE.md](CLAUDE.md) for principles, data sources and open decisions.

## Data attribution

This project will use data from OpenStreetMap contributors (ODbL) and from other providers. A full attribution list will be kept in `docs/` as data sources are adopted.
